# spatial

## Overview

This module provides utilities for working with 3D geometry, including points, lines, vectors, surface normals, and coordinate systems. Cartesian axis types are re-exported from `cartesian_axis`.

## Components

| Component | Description |
|-----------|-------------|
| [coordinate_type.py](./coordinate_type.py) | `CoordinateType` enum (Cartesian, Spherical, Cylindrical). |
| [point/](./point/README.md) | 3D point representation and operations. |
| [line/](./line/README.md) | 3D line segment representation and operations. |
| [vector/](./vector/README.md) | 3D vectors, vector pairs, and orthonormal bases. |
| [normal/](./normal/README.md) | Surface normal values and normal maps. |
