# point

## Overview

This module provides utilities for working with 3D points, including single points and collections of points.

## Components

| Component | Description |
|-----------|-------------|
| [base.py](./base.py) | Abstract `Point3D` over scalar or array coordinates. |
| [point.py](./point.py) | Class representing a single 3D point with x, y, z coordinates. |
| [points.py](./points.py) | Class representing a collection of 3D points with batch operations. |
