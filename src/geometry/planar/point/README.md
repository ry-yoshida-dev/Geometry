# point

## Overview

This module provides utilities for working with 2D points, including single points and collections of points.

## Components

| Component | Description |
|-----------|-------------|
| [base.py](./base.py) | Abstract `Point2D` over scalar or array coordinates. |
| [point.py](./point.py) | Class representing a single 2D point with x, y coordinates. |
| [points.py](./points.py) | Class representing a collection of 2D points with batch operations. |
